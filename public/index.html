How to run the full demo (5 min)
  1. Pick a mode above the chat header — Balanced first.
  2. Click Run 15 (quick). Watch the routing evidence fill in the Analytics tab.
  3. When done, switch mode to Cost → Run 15 again. Then Quality → Run 15.

How to run the toolkit evaluation (first time, ~15 min)
  1. Install toolkit — click below. One-time git clone + pip install. Needs Python 3.9+ and Git.
  2. Deploy baseline & judge — expand "Deploy a recommended model" below.
  3. Pick router / baseline / judge from the dropdowns.
  4. Dry run first — validates the dataset, no API cost.
  5. Live evaluation — click "Run live evaluation". Watch the console below.
  6. Open dashboard — button below the console opens the toolkit's HTML report.
