BENCHMARK

Run a full evaluation

The Model Router Auto Evaluation toolkit runs your prompts against router + baseline, scores quality with a judge model, and produces a full dashboard.

How to run the evaluation (first time, ~15 min)
  1. Install toolkit — click below. One-time git clone + pip install. Needs Python 3.9+ and Git. RouteLab auto-patches the toolkit's client for Entra ID.
  2. Auth — already handled. Setup wizard signed you in and wrote .env. RouteLab reuses that session (Entra ID via az, or AZURE_OPENAI_API_KEY if you provided one). Check the Auth chip below — only re-run az login if the token has expired.
  3. Deploy baseline & judge — expand "Deploy a recommended model" below. Deploy gpt-5.6-luna if you want a strong judge; gpt-5.2 is a solid baseline.
  4. Pick dataset — Built-in 15/30 for a quick benchmark, a bundled toolkit dataset, or Upload your own dataset (JSONL / JSON / CSV / plain text) — RouteLab auto-fills missing ids.
  5. Pick router / baseline / judge from the dropdowns.
  6. Dry run first — click "Dry run (validate)". Validates the dataset, no API cost.
  7. Live evaluation — click "Run live evaluation". Watch the console below. Chat is locked while it runs.
  8. Open dashboard — button below the console opens the toolkit's HTML report in your default browser.
  9. Repeat per mode — change router to mr-cost, then mr-quality, run again. Compare 3 dashboards.
