BENCHMARK

Run a full evaluation

The Model Router Auto Evaluation toolkit runs your prompts against router + baseline, scores quality with a judge model, and produces a full dashboard.

How to run the evaluation (first time, ~15 min)
  1. Install toolkit — click below. One-time git clone + pip install. Needs Python 3.9+ and Git.
  2. Add an API key — the toolkit needs AZURE_OPENAI_API_KEY in the app's .env (Entra ID is not supported yet). The chip below tells you if the key is present.
  3. Deploy baseline & judge — expand "Deploy a recommended model" below. Deploy gpt-5.6-luna if you want a strong judge; gpt-5.2 is already there for baseline.
  4. Pick dataset — Built-in scenarios for a controlled 15/30-prompt benchmark, or your own conversations for real-workload data.
  5. Pick router / baseline / judge from the dropdowns.
  6. Dry run first — validates the dataset, no API cost. Click "Dry run (validate)".
  7. Live evaluation — click "Run live evaluation". Watch the console below. Chat is locked while it runs.
  8. Open dashboard — button below the console opens the toolkit's HTML report in your default browser.
  9. Repeat per mode — change router to mr-cost, then mr-quality, run again. Compare 3 dashboards.
